# استخراج بيانات السوق للاستيراد

تشتغل هالمهارة على الصفحة اللي المستخدم فاتحها في متصفحه وهو مسجل دخول بحسابه. الناتج ملف CSV بصيغة الاستيراد الثابتة بالضبط.

## القواعد
- **اقرأ فقط.** لا تدخل بيانات دخول، ولا تضغط شراء أو اشتراك، ولا تغيّر شي في الحساب.
- لو الصفحة طلبت تسجيل دخول أو تحقق، وقف واطلب من المستخدم يكمله بنفسه.
- **لا تخترع أي قيمة.** الحقل اللي ما تلقاه في الصفحة تتركه فاضي.
- المستخدم مسؤول عن الالتزام بشروط استخدام المنصة. نبّهه مرة وحدة في أول تشغيل.
- استخرج الصفوف المعروضة في الصفحة الحالية بس، أو اللي يحددها المستخدم. لا تتنقل بين صفحات كثيرة بدون ما يطلب.

## الصيغة (بالترتيب، وأول صف عناوين)
```
المنصة,النوع,صفقة أم عرض,الوصف / الموقع,المساحة (م²),السعر الإجمالي (ريال),سعر المتر مباشرة,التاريخ,الرابط,يدخل؟,ملاحظة
```
- **المنصة:** سهيل، أو البورصة العقارية، أو مؤشر إيجار، أو إيجار، أو عقار، أو بيوت، أو مكتب عقاري، أو أخرى.
- **النوع:** أرض، أو شقة، أو فيلا، أو محل أو معرض، أو إيجار محل أو معرض، أو إيجار شقة.
- **صفقة أم عرض:**
  - صفقات وزارة العدل = «صفقة».
  - الإعلانات = «عرض».
  - المتوسطات = «مؤشر».
- **المساحة والسعر:** اكتب الأرقام بدون فواصل. وإذا الصفحة تعطي سعر المتر بس، ضعه في «سعر المتر مباشرة».
- **التاريخ:** YYYY-MM.
- **يدخل؟:** 1 افتراضياً.
- **ملاحظة:** اكتب أساس المساحة إذا مذكور (صك، أو إجمالية، أو صافية)، والدور، والعمر، وأي شي يميز الصف.

## المخرج
1. **ملخص سطرين:** كم صف، ومن أي منصة، وأي حي، وأي فترة.
2. **كتلة CSV كاملة** جاهزة للنسخ، أو ملف `market_import.csv` إذا البيئة تسمح.
3. **قائمة بالصفوف اللي فيها نقص**، مثل مساحة مفقودة أو تاريخ غير واضح.
