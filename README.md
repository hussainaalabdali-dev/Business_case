# حزمة بناء منصة دراسة جدوى التطوير العقاري (v1)

هالحزمة فيها كل اللي يحتاجه Claude Code عشان يبني النسخة الأولى من الموقع.

## المحتوى
```
CLAUDE.md                     تعليمات البناء الثابتة لـ Claude Code (التقنية والقواعد والأوامر)
docs/PRODUCT.md               المنتج: المستخدم، والقيمة، والنطاق، والمخاطر
docs/ENGINE_SPEC.md           مواصفات المحرك: كل معادلة (المرجع الأساسي)
docs/SCREENS.md               الصفحات وتدفق المستخدم وتقرير PDF
docs/DATA.md                  قاعدة البيانات ومصادر البيانات النظامية
docs/IMPORT_FORMAT.md         صيغة استيراد بيانات السوق
docs/ROADMAP.md               المراحل ومعايير القبول
fixtures/*.json               13 حالة اختبار من النموذج المرجعي + التدفقات الشهرية للحالة الأساسية
reference/engine_reference.py محرك مرجعي بـ Python ينجح على كل الحالات (python reference/engine_reference.py)
reference/feasibility_model.xlsx   النموذج المرجعي (أبحر الجنوبية)
reference/template_ui_v2.xlsx      قالب الواجهة المرتب حسب المراحل (مرجع للشاشات)
skills/market-data-extract/   مهارة للمستخدم يستخدمها مع إضافة Claude في المتصفح
```

## كيف تبدأ
1. أنشئ مستودع Git جديد وانسخ محتوى الحزمة فيه، وسوِّ commit أول.
2. افتح Claude Code داخل المستودع.
3. أعطه الأمر التالي:

```
اقرأ CLAUDE.md ثم كل الملفات في docs/ بالترتيب المذكور.
شغّل: python reference/engine_reference.py وتأكد إن كل الحالات OK.
بعدها اعرض عليّ خطة تنفيذ المرحلة 1 فقط من docs/ROADMAP.md
(المهام، والملفات اللي بتنشئها، وكيف بتتحقق من معايير القبول)،
ولا تكتب كود قبل ما أوافق على الخطة.
```

4. راجع الخطة، ووافق، وتابع مهمة بمهمة. ولا تنتقل للمرحلة 2 إلا بعد ما ينجح `make test`.

## قرارات محسومة
- المستخدم الأول: المطوّر الصغير والمتوسط.
- اللغة: عربي فقط.
- الحسابات: تسجيل بدون دفع.
- التقرير: PDF بشكل مذكرة لجنة الاستثمار.
- البيانات: مفتوحة (وزارة العدل والهيئة)، والباقي استيراد من المستخدم. لا سحب آلي من المنصات.

## مخاطر مفتوحة قبل الإطلاق العام
- موقع الاستضافة ومتطلبات نظام حماية البيانات الشخصية.
- الشكل الفعلي لبيانات وزارة العدل لجدة (أول مهمة في المرحلة 2).
- التحقق من طلب المطورين: جرّب القالب معهم بالتوازي مع البناء.
